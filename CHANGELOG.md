# Changelog

## v3.0.0

- Added clean recording as the default mode.
- Added optional burned timestamp overlay.
- Added timestamp position selector.
- Added timestamp text field.
- Improved audio device scanning.
- Reduced noisy ffplay terminal output.
- Added safer recording filenames showing clean/timestamp mode.

## v2.0.0

- Added session recording with FFmpeg.
- Added start/stop recording controls.
- Added recording timer.
- Added recording save folder picker.
- Added recording presets.
- Added optional audio capture.
- Added review/light scrubbing for the last recording.

## v1.0.0

- Added Raspberry Pi-native V4L2 camera control GUI.
- Added OBSBOT Meet SE support through standard Linux controls.
- Added PTZ D-pad.
- Added zoom controls.
- Added preview through ffplay.
- Added snapshots.
- Added focus, exposure, white balance, and image tuning controls.
